About this platform

What AI Support Desk does and how it's built.

What it does

AI Support Desk lets employees raise IT tickets and get an immediate AI-generated summary and suggested fix before a human ever looks at the queue. If the suggestion resolves the issue, the ticket closes itself; if not, it's escalated to the open ticket queue with the AI's notes attached. The AI Agent page also offers open-ended troubleshooting chat for questions that don't need a formal ticket.

How it's built

  • Flask & SQLite

    A single Flask app serves the pages and a JSON API; tickets, users, and chat history are stored in a local SQLite database.

  • Google Gemini

    Ticket analysis and the AI Agent chat both call the Gemini API directly over REST, with your recent chat history sent along for context.

  • Session-based auth

    Passwords are hashed with Werkzeug's security helpers; signed-in state is kept in a server-side session cookie.
